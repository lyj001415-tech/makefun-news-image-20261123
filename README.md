A program that draws a newspaper front page summing up Monday 23 November 2026's world news in one image. It renders everything in code with the Node standard library only — its own rasterizer, a hand-built bitmap font, five pictograms and a hand-rolled PNG encoder — and writes a deterministic 1024×1024 `entry.png` (identical bytes on every run).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
